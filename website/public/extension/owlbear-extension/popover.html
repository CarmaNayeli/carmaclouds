Commands

!roll or !r — roll a dice formula

Dice Syntax

!r 1d20Single die
!r 2d6+3Dice + flat modifier
!r 1d8+1d6-1Multiple dice groups
!r d20Omit count for ×1

Stat Variables (use {curly braces})

{STR} {DEX} {CON}
{INT} {WIS} {CHA}
Ability modifiers (e.g. WIS 19 → +4)
{WIS_SAVE}Saving throw total (includes prof)
{PROF}Proficiency bonus
{PERCEPTION}Skill totals by full name

Examples

!r 1d20+{WIS}Wisdom check
!r 1d20+{WIS_SAVE}Wisdom saving throw
!r 1d20+{PERCEPTION}Perception check
!r 2d6+{STR}Greatsword damage

⚠️ Variables resolve from your active character's stats. Resync from DiceCloud if values look wrong.

🎲 If Dice+ is installed, the 3D die and chat result are always the same roll.
